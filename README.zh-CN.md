### 为什么选择 macshot？

- **截图标注一体化** — 选择区域、绘制箭头/文字/形状/模糊、复制到剪贴板。一个快捷键，零摩擦。
- **内置编辑器的录屏功能** — 录制任意区域或全屏为 MP4/GIF，支持系统音频+麦克风。音轨合并对话框支持独立音量控制。无需离开应用即可剪辑导出。
- **滚动截屏** — 选择区域后滚动，macshot 自动将其拼接成一张无缝的长图（或宽图）。
- **任意上传** — 一键上传到 Google Drive、imgbb 或任何 S3 兼容服务（Cloudflare R2、AWS S3、MinIO 等）。链接立即复制到剪贴板。
- **轻量原生** — 空闲时约 8 MB 内存。常驻菜单栏。使用 Swift 和 AppKit 构建，而非伪装的浏览器。
- **2 种语言** — 英语、中文（简体）。自动检测系统语言。

## 安装

**Homebrew:**
```bash
brew install fxzer/macshot/macshot
```

**手动安装：** 从 [发布页](https://github.com/fxzer/macshot/releases) 下载最新的 `.dmg`，打开后拖拽到 `/Applications`。

---

## 快速开始

1. 启动 macshot — 它会出现在菜单栏中
2. 按下 `Cmd+Shift+X` 截图
3. 拖动选择区域，使用工具栏标注，按 `Cmd+C` 复制
4. 按 `Esc` 取消

<summary><b>全部功能</b></summary>

### 截图
- **即时截图** — 全局快捷键冻结屏幕，选择任意区域
- **窗口吸附** — 悬停在窗口上点击即可精确捕获；`Tab` 切换吸附，`F` 全屏
- **滚动截屏** — 自动检测垂直或水平滚动，使用 Apple Vision 拼接，在截图区域旁实时预览
- **延迟截图** — 3/5/10/30 秒倒计时，通过菜单栏设置。Esc 取消。
- **多显示器** — 同时捕获所有屏幕；跨屏幕拖动选择可拼接图像
- **快速保存** — `Cmd+Shift+S` 选择并立即保存/复制无需标注。Enter 键根据偏好保存/复制。
- **快速 OCR** — `Cmd+Shift+T` 选择并立即提取文本

### 标注工具
- **箭头** — 5 种样式：单线、粗线/横幅、双线、开放、尾线；翻转方向开关；右键添加锚点制作复杂曲线
- **形状** — 矩形和椭圆，3 种填充模式（描边、描边+填充、填充），圆角滑块
- **文本** — 富文本格式（粗体/斜体/下划线/删除线），可调整文本框大小，左/中/右对齐，背景填充和轮廓颜色，点击重新编辑
- **铅笔和标记** — 自由绘制，可选平滑；智能标记模式通过 OCR 吸附到文本行
- **数字标记** — 自动递增（1/I/A/a 格式），可选指针锥
- **印章/表情符号** — 21 个快速表情，100+ 个分类选择器，或加载任何图片
- **编辑（像素化/模糊/纯色/擦除）** — 统一编辑工具，4 种模式：像素化、高斯模糊、纯色填充，或智能擦除采样周围颜色实现隐形内容移除。自动编辑 PII（邮箱、电话、信用卡、SSN、API 密钥），自动检测人脸和人物，或在"仅文本"模式下绘制只编辑区域中的文本
- **测量** — 像素标尺，px/pt 切换；按住 `1` 或 `2` 自动测量
- **放大镜** — 2 倍放大
- **颜色取样器** — 吸管拾取任何颜色；右键复制十六进制；自动保存到自定义色板槽
- **空格重新定位** — 绘制时按住空格移动形状而不改变其大小
- **旋转** — 通过手柄旋转形状，Shift 90° 吸附
- **点击选择** — 点击任何标注选中它，然后编辑属性（描边、样式、填充）、拖动移动、通过手柄调整大小、旋转或删除 — 无需切换工具

### 屏幕录制
- **MP4 (H.264)** 最高 120fps 或 **GIF** (5/10/15fps)
- **系统音频捕获** — 开关切换，排除 macshot 自己的声音
- **麦克风录制** — 与屏幕捕获同时录制语音旁白（首次使用时请求权限）
- **鼠标点击高亮** — 录制期间点击时的视觉波纹
- **选择边框** — 录制期间可见的捕获区域轮廓
- **菜单栏停止按钮** — 从菜单栏图标停止录制（即使图标隐藏也会出现）
- **快速设置弹出窗口** — 即时更改格式、FPS 和录制后操作，无需打开偏好设置
- **视频编辑器** — 剪辑时间轴、静音/剥离音频、播放/暂停、保存（另存为）、上传、在 Finder 中显示

### 输出和上传
- **格式** — PNG、JPEG、HEIC、WebP，带质量滑块
- **Google Drive** — 一次登录，上传到私人"macshot"文件夹
- **imgbb** — 匿名图片托管，带可共享链接
- **S3 兼容** — 上传到 Cloudflare R2、AWS S3、MinIO、DigitalOcean Spaces、Backblaze B2 等
- **Retina 缩小** — 可选 1x 导出以获得更小的文件
- **sRGB 色彩配置文件** — 可选嵌入以实现跨显示一致性

### 编辑器窗口
- 独立可调整大小的窗口，完整标注工具，美化预览
- **添加截图** — 捕获额外的屏幕区域并将它们组合成一张图片，拖动重新定位
- 裁剪（带三分法则网格）、水平/垂直翻转、缩放 0.1x–8x
- 顶部栏显示像素尺寸、缩放下拉菜单（预设、适应画布、放大/缩小）

### 美化
- macOS 窗口框架，带红绿灯、阴影和渐变背景
- 30 种渐变样式，包括 7 种网格渐变（macOS 15+），可调整内边距/圆角/阴影

### 图像效果（调整）
- 非破坏性 CIFilter 调整：亮度、对比度、饱和度、锐度
- 8 种预设：黑白、单色、棕褐色、铬色、褪色、即时、鲜艳
- 独立工作或与美化结合使用
- 覆盖层中实时预览

### 其他
- **OCR** — 使用 Apple Vision 提取文本（macOS 13+ 自动检测所有语言），自动复制到剪贴板，翻译到 30 多种语言，Google AI 搜索
- **反转颜色** — 一键颜色反转，应用两次恢复
- **背景移除** — Apple Vision 前景遮罩（macOS 14+）
- **固定到屏幕** — 浮动置顶窗口
- **浮动缩略图** — 自动关闭预览，带复制/保存/固定/编辑/上传
- **可编辑标注的截图历史** — 菜单栏子菜单 + 下拉历史面板（`Cmd+Shift+H`）。在编辑器中重新打开任何捕获，保留实时标注 — 编辑后按完成保存。拖放、快速查看和右键操作
- **二维码和条形码检测** — 内联打开/复制操作
- **吸附对齐指南** — 标注吸附到中线和边缘
- **自动更新**（通过 Sparkle）
- **空闲时 ~8 MB 内存**
